# ScoreCardUWB · UWB 定位对接说明

## 模块

路径：`Assets/Character/Scripts/Venue/Uwb/`

| 文件 | 职责 |
|------|------|
| `UwbRuntime` | 总入口（挂 VenueSync 上） |
| `UwbMqttTransport` / `UwbUdpTransport` | 真机推送（优先 MQTT） |
| `UwbMockTransport` | 无真机时发官方格式 Pos JSON |
| `UwbReplayTransport` | 回放录制 jsonl |
| `UwbRecorder` | 异步 JSONL 录制 |
| `UwbVenueBridge` | 解析 → 场馆坐标 → `VenuePlayerSync` |
| `UwbCoordinateMapper` | Nooploop 轴 → 场馆米制 |
| `UwbTagRegistry` | uid → 玩家 id/队/名 |

官方文档：https://support.nooploop.com/cn/ips/api

## 推荐链路

真机：**IPS Tools → MQTT 推送**（时延最低）→ `UwbRuntime` `LiveMqtt`  
备选：UDP / webhook（本工程先做 MQTT + UDP）

HTTP ` /openapi/v1/devices` 只适合查设备列表，不适合实时位置。

## 场景使用

1. `VenueSync` 上确保有 `VenueSpace` + `VenuePlayerSync` + **`UwbRuntime`**
2. `UwbRuntime.enableUwb = true`（会自动关 `VenuePlayerMockFeed.playing`）
3. **打包后改配置**：屏幕任意位置 **连续点 2 次** 弹出 UWB 设置面板 → 改完点「应用」
4. 配置持久化文件：`Application.persistentDataPath/uwb_config.json`（下次启动自动加载）
5. **开机行为**
   - **Unity Editor**：自动 **Mock**（方便调试；要连真机请在设置里手动切 LiveMqtt）
   - **正式包 exe/android**：用已保存 Broker 自动连 **LiveMqtt**；连不上则无玩家并弹窗，**不会**自动开 Mock
6. **Mock / Replay**（正式包）：仅设置里手动「应用」后于本次运行生效；**不写进开机默认**
7. 真机 Live → **自动按日录制** `uwb_records/uwb_yyyyMMdd.jsonl`（同日追加）
8. Replay：需手动选日志文件；无文件不回放；可设循环时段

## 录制格式（JSONL）

```json
{"t":1.234,"ms":1732425600123,"raw":"{\"name\":\"Pos\",\"uid\":\"...\",\"data\":{...}}"}
```

- `t`：相对开录秒
- `ms`：UTC unix 毫秒
- `raw`：原始推送字符串（官方 JSON 或旧桥 type=14）

## 坐标

默认：`venueX=uwbX`，`venueY=uwbZ(高度，可 flatten=0)`，`venueZ=uwbY`。  
用 `UwbCoordinateMapper` 的轴/偏移/缩放标定到 `VenueSpace`。

- **Mock**：活动区以场馆原点为中心（`±mockAreaX/2` × `±mockAreaY/2`），对齐旧 `VenuePlayerMockFeed`。
- **真机**：若 IPS 原点在场地角点，请在 `mapper.offsetMeters` 里减半场尺寸（例如 18×10 场可试 `(-9,0,-5)`），再微调。

## 与旧 piupiu-map

旧项目是 `ws://…:8080/websocket` + type=14，不是 Nooploop 直连。  
本工程解析器兼容该外壳；新部署请直接用官方 MQTT/UDP。
