一、对上一版文档的修正
上一版（2026-11-26 早些时候）有以下不准确，已在本版改正：
1. 「现状结论」里说没有场次运行时、HUD 只靠 UwbHudMock 假数据——已过时。ScoreCardMatchRuntime 已订阅
   ScoreCardCommandEvent，写入 UwbHudData 和 ScoreCardCombatState，并向 3D 层发 CombatCue。
2. 「HUD 档位 UI 已有雏形，缺死亡灰卡/待复活」——已过时。10/20/40 三档底卡、头顶标牌、倒计时/待复活均已做完，
   但「灰」只有透明度降低，没有灰化（见 P13）。
3. 「特效表 BUFF 已接」——只对了一半。取得 BUFF 的瞬间会播一次 Redbuff/Bluebuff 预制体（2.5 秒后销毁），
   策划要求的是「持续到死亡 + 姓名旁 ICON」，目前都没有。
4. 「VFX_UWB_2.5DView_BUFF_Heling 回血特效已接」——当时代码里有 NotifyHp 对比血量回升的逻辑，但 ScoreCardMatchRuntime
   所有路径都传 playHpFx:false，从未触发。2026-11-27 起 REFRESH_DATA 路径已打开（见 P20）。
5. 「积分模式 Mock 已接 BUFF/回血」——不准确。ScoreCardScoreModeMock 会发 S4/REFRESH_DATA、SHOOT(HIT/KILL)、
   MULTI_KILL、TOWER_KILL、PLAYER_REVIVE，但不发 RED/BLUE_BUFF_CAPTURED、FIRST_BLOOD，也没有回血。
6. 「P26–27 击杀流/高光 协议有，单屏 UI 未做」——结论没错，但还要补一条：MULTI_KILL/FIRST_BLOOD 会发出
   MultiKill cue，VenueCombatFxPlayer.HandleCue 没有对应分支，所以现在既没有 UI 也没有特效。
7. 上一版只覆盖了 P10–P39 中和特效相关的部分，漏掉了全屏阶段（P2–P9）、双榜（P3–P6）、人物动作（P17）、
   地图机制（P23–P25）、音效（P37）、最后击杀回顾（P29–P32）、异常恢复（P33）。本版补全。
